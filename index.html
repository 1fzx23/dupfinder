dupfinder

一个零依赖的命令行工具，按 SHA-256 内容哈希 找出真正的重复文件，告诉你磁盘里能省下多少空间。

⭐ 在 GitHub 上查看 ▶ 在浏览器里试一下

它长什么样

扫描一个目录，立刻得到重复分组与可节省空间——默认只读，绝不删文件。

核心特性

小、快、安全。

🪶

零依赖

只用 Python 标准库，Python 3.8+ 直接运行，无需 pip install。

🔒

默认只读

只报告重复文件，不删任何东西。删除需显式加 --delete 并确认。

🧠

两步加速

先按文件大小分桶，只对"大小相同"的文件做哈希，避免无谓的磁盘读取。

🤖

JSON 输出

--json 输出机器可读结果，方便接入脚本或其他工具。

🧹

安全删除

--delete 每组保留一个，删除其余副本；--yes 可跳过确认用于自动化。

💻

跨平台

Windows / macOS / Linux 通用，纯 Python 实现。

安装与使用

不需要安装，直接用 Python 运行即可。

# 方式一：直接运行本地文件
python dupfinder.py <目录>

# 方式二：从 GitHub 克隆
git clone https://github.com/1fzx23/dupfinder.git
cd dupfinder
python dupfinder.py <目录>

常用命令

用途命令
找出重复文件（只读报告）python dupfinder.py DIR
只看大于 1MB 的文件python dupfinder.py DIR --min-size 1048576
输出 JSONpython dupfinder.py DIR --json
删除多余副本（保留每组第一个）python dupfinder.py DIR --delete
删除且跳过确认（脚本用）python dupfinder.py DIR --delete --yes

工作原理

为什么它找得准又找得快。

1️⃣

按大小分桶

遍历目录，把相同大小的文件归到一组。大小都不同的文件不可能重复，直接排除。

2️⃣

按内容哈希

只对"大小相同"的候选文件计算 SHA-256。哈希相同，内容必然相同。

3️⃣

报告 / 清理

输出重复分组与可节省空间；--delete 时每组保留第一个，删除其余。
